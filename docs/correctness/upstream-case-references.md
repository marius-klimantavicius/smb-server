# Exact local case references for the Samba ledger

The [continuation ledger](upstream-samba-continuation.md) uses bounded family
references where several local cases jointly cover a source function. This index
expands each such reference against the 3,144 unique registrations at the final
protocol handoff. These are exact case names, not extra tests, new pass counts,
or a claim that every assertion in the original upstream workflow executed. The
ledger explains the matched public facets, source-policy differences and blockers.
Overlapping prefixes can list the same registration; never add these list lengths.
